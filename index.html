Add the group's learner names in bulk, then attach each learner's assignment PDF once. On the "Mark Assignment" tab, the assessor picks a name from the list and that learner's PDF loads automatically in the reading panel — no need to hunt for the right file each time. If a PDF's filename doesn't match anyone in the list, it's still added automatically using a name guessed from the file — click any name below to rename it if the guess isn't right. The learner list and each learner's marking progress (decisions and comments) save automatically — synced across machines if Firebase is configured (see the script near the top of the file), otherwise saved to this browser only. Attached PDFs are saved in this browser's durable storage and remain available after refreshing the page or closing and reopening the system.
Select all learner PDFs at once (or a single .zip of PDFs). Files are matched to names automatically by filename (e.g. "J_Smith.pdf" matches "J. Smith") — anything that doesn't match can be attached manually below.
For a .zip where each learner has their own folder (folder name = learner name) containing their assignment PDF, e.g. J. Smith/assignment.pdf. The folder name is used as the learner's name directly — no guessing from the PDF's filename. If a folder has no matching learner yet, one is added automatically.
Cloud sync of individual PDFs can be flaky across browsers. For a rock-solid alternative: attach PDFs here, click "Download all PDFs as .zip" below, then upload that file as assignments.zip in the same folder as this page (e.g. commit it to the same GitHub repo, right beside index.html). From then on, every device that opens this page will automatically load all PDFs straight from that file — a plain download, not a database sync, so it works identically everywhere.
